Color kind calibration

What kind of color is this? Each color is shown alone; answer with the kind you would call it, the first that comes, from the kinds set below. A color between two kinds takes both: Space, then the two kinds. No kind is an answer too. The colors are dealt by make_kind_deal.js, a grid over hue, cusp-relative lightness and chroma share, and come in random order. A pass names every color once; the map is two passes on different days: download the first pass's log, clear it, run the second. The log is kept in this browser between visits and can be downloaded and loaded back.

Color

Keys: Space before the two kinds of a color between them; Backspace takes the last answer back and shows its color again.

Setup

A round is one sitting; the next Start takes the next colors not yet named.

Kinds

Comma-separated, each kind with the hex of the swatch on its button, or none; fixed once a color is named, until the log is cleared.
